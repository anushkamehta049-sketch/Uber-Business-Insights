# 🚖 Uber Data Analysis Dashboard | Power BI

## 📊 Project Overview
This project presents an **interactive Power BI dashboard** built using Uber ride data to analyze trip patterns, demand fluctuations, and key performance metrics.  
The dashboard helps stakeholders understand **when, where, and how Uber services are being used**, enabling better operational and strategic decisions.

---

## 🎯 Business Objective
To analyze Uber ride data and derive actionable insights related to:
- Trip demand trends
- Time-based ride distribution
- Location-based performance
- Overall ride activity patterns

---

## 📌 Key KPIs Tracked
- Total Trips
- Trips by Hour, Day & Month
- Peak Demand Time Slots
- Location-wise Ride Distribution
- Ride Trends Over Time

---

## 🛠 Tools & Technologies Used
- **Power BI** – Data visualization & dashboard creation  
- **Power Query** – Data cleaning & transformation  
- **DAX** – Measures & calculated fields  
- **Excel / CSV** – Data source

---

## 📈 Dashboard Features
- Interactive filters for time and location
- Trend analysis using line and bar charts
- Heatmap-style insights for peak hours
- Clean, business-friendly visual layout

---

## 💡 Insights Generated
- Identified peak ride hours and high-demand days
- Observed ride demand growth patterns
- Analyzed location-wise ride concentration
- Supported data-driven operational planning
